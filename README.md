# 影像训练数据 · 病例切分平台

把病例精确切分为**训练集（组 1）**与**评估集（组 2）**，保证：

- 同一患者的所有病例必须在同一组；
- 患者亲属关系（含传递闭包）相连的病例必须在同一组；
- 两组中标签 0/1 的病例数**精确等于**填写的配额（硬约束，不使用近似比例）；
- 可锁定部分病例的分组；
- 无解时给出**不可再缩减的冲突条件集（MUS）**，逐条标注来源：配额 / 锁定 / 亲属关系。

技术栈：FastAPI + SQLite（WAL）+ z3-solver，原生 HTML/JS 前端，Docker Compose 一键启动。

## 一、快速启动（Docker Compose）

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

数据持久化在命名卷 `split-data`（容器内 `/app/data/app.db`）。停止与清理：

```bash
docker compose down          # 保留数据
docker compose down -v       # 同时删除数据卷
```

## 二、本地直接运行（可选）

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

可用环境变量 `SPLIT_DB_PATH` 覆盖 SQLite 文件路径。

## 三、操作流程

1. **数据上传**：上传病例 CSV（`病例号,患者号,标签`，标签仅 0/1，≤200 行），
   再上传亲属对 CSV（`患者A,患者B`，≤200 行）。模板可在页面直接下载，
   示例见 `samples/`。校验失败（空值、重复病例号、标签非法、引用未知患者等）
   整体拒绝，**不会改动已入库的数据**。
2. **配额与锁定**：填写两组 × 两标签的**精确数量**；可在锁定表逐病例指定分组。
   每次保存都会产生一个新的输入版本。
3. **求解与发布**：点击“运行 z3 求解”。
   - 有解：展示完整切分清单预览与四格实际计数，可一键发布；
   - 无解：列出不可再缩减冲突条件（删除其中任意一条，其余约束即可满足），
     并按配额/锁定/亲属关系分类，无近似比例方案。
4. **已发布清单**：清单与其**输入依据**（病例、亲属、配额、锁定快照）一起持久化，
   可下载 CSV；失效清单禁止下载但记录保留可审计。
5. **版本记录**：每次输入变动的类型与详情。

## 四、失效语义（关键设计）

- 病例、亲属、配额、锁定中**任何一项变动**都会使输入版本 `+1`；即使改回原值，
  版本号也不回退（每次保存都是一次新的写操作，均有版本日志）。
- 版本一旦变动：
  - 所有旧预览令牌立即作废，不能再发布；
  - 所有已发布清单在同一数据库事务内被标记 `invalidated`，不能再下载；
  - 服务重启会清空内存中的预览令牌，重启后不存在可发布的旧预览。
- 求解在数据库事务之外执行：计算期间允许修改输入。若计算期间版本发生变化，
  本次结果直接作废（HTTP 409），不生成预览。
- 发布时在 `BEGIN IMMEDIATE` 事务内再次核对版本，堵住“检查后、写入前”的交错窗口；
  两个浏览器窗口同时操作也不会放出过期或半份清单。

## 五、API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 当前输入版本、数据概览、清单列表 |
| POST | `/api/upload/cases` | 上传/替换病例 CSV（multipart） |
| POST | `/api/upload/relatives` | 上传/替换亲属对 CSV（multipart） |
| PUT | `/api/quotas` | 保存四格精确配额 |
| PUT | `/api/locks` | 保存完整锁定表 |
| POST | `/api/solve` | z3 求解，有解返回预览令牌 |
| POST | `/api/publish` | 按预览令牌发布（过期返回 409） |
| GET | `/api/manifests` | 已发布清单列表（含失效标记） |
| GET | `/api/manifests/{id}` | 清单 + 输入依据明细 |
| GET | `/api/manifests/{id}/download` | 下载切分 CSV（失效返回 409） |
| GET | `/api/version-log` | 输入版本变动记录 |

## 六、自测

```bash
pip install pytest httpx python-multipart
python3 -m pytest tests/ -v
```

覆盖：连通分量与传递关系、精确配额、锁定、三类来源的 MUS 及其不可再缩减性、
上传校验与行数上限、发布/下载全链路、输入变动后预览与清单永久失效、
重启持久化、并发写版本一致性（21 个用例）。
